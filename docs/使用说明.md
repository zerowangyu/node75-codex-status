# 安装与使用说明

## 安装前准备

- Apple Silicon Mac，macOS 12+。
- NuPhy Node75 LP 与 2.4G 接收器。键盘切为无线模式，Fn + 4 选择 2.4G。
- Python 3.8+。如果尚未安装，可从 [Python 官网](https://www.python.org/downloads/macos/) 或 Homebrew 安装；Homebrew 用户可运行 `brew install python`。
- 官方 Codex CLI 已登录，并支持本程序使用的 Hook 与 app-server 接口。软件先查找安装配置和 PATH，再尝试桌面版自带 CLI。找不到时见 [常见问题](常见问题.md)。

## 安装程序与接入

从 GitHub Release 解压 `.app`，放到用户“应用程序”目录 `~/Applications` 或系统 `/Applications` 后打开。初次打开显示接入页面；以后从键盘菜单的“Codex 接入设置…”进入。

点击“安装或修复接入”。安装器会配置当前用户的灯光后台，合并 7 个 Hook，保留其他 Hook。已有配置如需修改，会在相同目录备份；内容不变时不重复写入。

接入页显示后台是否运行、Hook 配置／信任／启用数量、键盘访问权限及最近收到的事件。点击“重新检查”刷新。成功接入应看到 7 个 Hook 已配置、可信且启用；未收到真实事件时可以尚无“最近事件”。

点“打开官方 Hook 审阅”，在官方 CLI 输入 `/hooks`，检查并信任定义。软件只查询信任状态，不替你修改信任记录。已信任且定义未改变的 Hook 无需重复信任。详情以 [Codex 官方说明](https://learn.chatgpt.com/docs/hooks) 为准。

macOS 请求输入监控权限时，在“系统设置 → 隐私与安全性 → 输入监控”中允许实际控制键盘的后台进程；它可能显示为 Python 或控制器。权限变更后暂停并恢复联动，再重新检查。该权限用于打开 HID 接口，程序不记录按键。

接入完成后，在 Codex 开始新一轮对话。若旧会话未加载新配置，重新打开会话或重启 Codex。

## 日常使用

菜单栏默认显示键盘图标和剩余额度。点击图标可查看任务、连接和额度详情，打开控制面板，或预览灯效。

- 慢闪：每 0.8 秒切换亮灭，表示运行。
- 快闪：每 0.2 秒切换亮灭，表示权限确认或受支持的提问等待。
- 常亮：完成时持续 10 秒。
- 空闲、中断或退出：恢复系统指示灯。

软件中的三个预览各持续 5 秒，不创建虚假聊天；期间仍处理真实 Hook，结束恢复真实任务状态。多聊天优先级为“等待确认 → 运行 → 完成”。后台重启会清空旧任务记录，等待新 Hook 建立状态。

菜单栏可选择“菜单栏显示状态文字”，也可关闭“图标旁显示剩余额度”。这些显示设置不影响灯光联动。

## 额度显示

菜单栏示例 `5h70% 周87%` 表示账户 5 小时额度剩余 70%、周额度剩余 87%。这只是展示示例；实际数字来自官方接口。接口只返回周额度时，仅显示周额度，5 小时项注明“暂未提供”。

每 5 分钟刷新一次，也能点“刷新使用额度”。菜单显示更新时间和北京时间重置时间。`*` 表示缓存已过期或刷新失败，数字保留上次值。退出菜单栏后不再定时查询，灯光后台本身不查询额度。

## 启动与退出

关闭面板不会退出软件。从应用程序目录再次打开 `.app`，或菜单中点“打开控制面板…”，可重新打开。

“登录时显示菜单栏”仅控制菜单栏登录项。灯光后台在安装接入时单独创建登录项。两者可以独立开关。

“退出菜单栏（灯光继续运行）”仅退出界面；“关闭灯光联动并退出”会同时停止后台。临时暂停／关闭后台后，下次登录仍会自动启动；长期关闭请解除接入。

## 停用与卸载

只想关闭灯光，保留额度显示：在“Codex 接入设置”点“解除 Codex 接入”。它移除本程序的 Hook、停止后台并删除后台登录项，保留其他 Hook 和菜单栏软件。

完整停用：先在菜单取消“登录时显示菜单栏”，再在接入页点“解除 Codex 接入”，最后“退出菜单栏”。随后可把 `.app` 移到废纸篓。

也可从源码目录执行 `python3 -B install.py uninstall`，或双击 `卸载.command`，一次停用两个登录项并移除本程序的 Hook。

停用后，运行文件、日志和 Hook 备份默认保留。需要清理时可手动删除 `~/Library/Application Support/Node75Codex/`，确认不需要后再删除本程序生成的 `hooks.json.node75-backup-*`。不要删除整个 Codex 配置目录，也不要删除其他 Hook。

## 文件位置

| 内容 | 默认位置 |
| --- | --- |
| 灯光后台、状态与日志 | `~/Library/Application Support/Node75Codex/` |
| 灯光后台登录项 | `~/Library/LaunchAgents/local.node75.codex-status.plist` |
| 菜单栏登录项 | `~/Library/LaunchAgents/local.node75.codex-menubar.plist` |
| Codex Hook | `~/.codex/hooks.json`；设置了 `CODEX_HOME` 时遵循该目录 |
| Hook 备份 | Hook 文件同目录下 `hooks.json.node75-backup-*` |

源码安装器会将界面复制到 `~/Applications/Node75 Status.app`。Release 用户按快速开始手动放置 `.app`，软件内安装接入仅安装灯光后台和 Hook，不会自动移动界面。
