# 源码、构建与实现

## 结构

| 文件 | 责任 |
| --- | --- |
| `node75_led.c` | macOS HID 控制器：匹配接收器，写标准 LED 输出，退出时恢复灯态 |
| `node75_status.py` | Unix socket 后台、Hook 入口、真实任务状态与预览协调 |
| `state.py` | 多聊天状态、优先级与完成超时 |
| `usage.py` | 官方 app-server 只读查询与额度缓存 |
| `integration.py` | 本程序 Hook 检查、信任状态查询、官方审阅入口 |
| `install.py` | 用户后台、登录项和 Hook 合并／解除 |
| `menubar.swift` | AppKit 菜单栏、控制面板与接入页面 |
| `build_release.py` / `build_menubar.py` | 构建 Apple Silicon 控制器和完整 `.app` |

## 构建

Apple Silicon、macOS 12+、Python 3.8+ 与 Apple Command Line Tools：

```sh
xcode-select --install
python3 -B build_release.py
```

不依赖第三方 Python 包。构建脚本仅在源码目录生成 `node75_led` 和 `Node75 Status.app`，不更改当前安装。Swift 目标为 `arm64-apple-macosx12.0`，控制器也指定 arm64 与 macOS 12 最低版本。发布包只针对 Apple Silicon；未验证 Intel。

也可以分步构建：

```sh
clang -O2 -Wall -Wextra -Werror -arch arm64 -mmacosx-version-min=12.0 node75_led.c \
  -framework CoreFoundation -framework CoreGraphics -framework IOKit -o node75_led
python3 -B build_menubar.py
```

`.app` 包含可用于软件内安装的 Payload、README、说明文档和 MIT License。签名是本地 ad-hoc 签名；没有 Developer ID 签名或 Apple 公证。

自动检查覆盖多聊天优先级、完成超时、迟到事件、中断、提问等待、Hook 字段过滤、安装合并、不阻塞任务、预览恢复、额度口径与缓存，以及只读协议、接入修复、解除、权限状态与官方信任检查。硬件效果仍需真实 Node75 和接收器验证；自动测试不能代替硬件兼容性验证。

## 本地调试

```sh
python3 -B node75_status.py status
python3 -B node75_status.py preview
python3 -B install.py review
```

`install.py review` 只输出待合并配置；输出含本机路径，勿直接公开。`node75_status.py daemon` 可以前台运行，但应先暂停已有后台，避免多个进程争用 socket 和指示灯。安装、解除与卸载会更改当前用户服务和 Hook，调试时按需执行。

## Hook 与协议

接入事件为 `UserPromptSubmit`、`PreToolUse`、`PostToolUse`、`PermissionRequest`、`Stop`、`Interrupt`、`SessionEnd`。超时设置为 1 秒；服务不在时 Hook 快速返回，不应阻塞任务。Hook 不返回权限审批决定；Stop 返回空对象。

Hook 从输入解析状态所需字段，通过本机 Unix socket 传递事件名、会话／轮次标识和等待标记。不会保存完整输入、正文、提示词或工具参数。信任状态通过官方 `hooks/list` 查询，信任操作留给官方 `/hooks` 界面。

额度通过 `codex app-server --stdio` 的 `initialize → initialized → account/rateLimits/read` 读取，优先使用 `rateLimitsByLimitId.codex`，按 `windowDurationMins` 识别 5 小时和每周。只缓存必要的窗口／百分比／时间，不缓存账户 ID、credits 或登录凭据。只读封装允许 `account/rateLimits/read`、`hooks/list`，拒绝其他方法。

HID 仅匹配 `19f5:2620` 的 Boot 键盘接口（Usage page 1、usage 6，输入 8 字节、输出 1 字节），Report ID 0，Caps LED bit 为 `0x02`。控制器没有按键发送操作。无线逐列、彩色和 NuPhy 原生动效命令尚未打通。

## 发布注意事项

仅发布源码白名单与重新构建的 `.app`。不要上传 runtime 状态、socket、日志、Hook 备份、账户缓存、私人路径或设备原始研究记录。Release 提供 SHA-256 校验文件。版本变更时同步构建脚本、CLI clientInfo 和文档中的版本。

官方 app-server 与 Hook 接口会变化。遇到升级后的兼容问题，应先用对应 CLI 版本的官方接口检查，不自行写入信任 hash、不绕过审核，也不借额度查询启动模型任务。
